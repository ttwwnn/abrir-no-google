Política de privacidade do Abrir no Google

Atualizada em 18 de novembro de 2026.

Que dados a ferramenta acessa

Só os arquivos que o próprio usuário abre no Mac com ela e que ela envia para o Google Drive dele (permissão drive.file). Ela não lê, não lista e não altera nenhum outro arquivo do Drive.

Onde os dados ficam

Os arquivos ficam no Google Drive do próprio usuário. A autorização de acesso fica guardada só no computador dele. Nenhum dado é enviado a servidores do autor nem a terceiros, e nada é vendido, compartilhado ou usado para publicidade.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de uso limitado.

Como revogar o acesso

A qualquer momento, em myaccount.google.com/permissions.
